# Incident: Approval Natural Fire Failure on 2026-09-30

## Summary

The final design reply reached Gmail at 19:56:14 JST, but no natural Design
Selection workflow started. Manual dispatch later detected the same reply and
completed selection and publication. No 2026-09-30 content requires replay.

## Confirmed failure boundary

```text
Yahoo reply
  -> Gmail Inbox                         OK
  -> Gmail Push                          OK
  -> Pub/Sub                             OK
  -> Approval Relay                      received delivery
  -> Gmail API history.list              FAILED: OAuth refresh invalid_grant
  -> relay_events creation               not reached
  -> GitHub workflow_dispatch            not reached
```

The Relay OAuth refresh token was expired or revoked. The Gmail watch remained
valid, and the push topic/subscription delivered notifications. The durable
cursor remained at history ID `35115`; watch state recorded history ID `35154`
with expiration `2026-10-06 03:17:10 JST`. The target reply did not create a
Relay event, proving the stop occurred before classification and dispatch.

## Why the fallback did not recover

The only fallback was GitHub Actions `on.schedule`. Although configured every
15 minutes, no scheduled run object was created during the relevant window.
GitHub-hosted schedule is best effort and did not provide the assumed recovery
SLA. The checker itself was healthy: a later manual dispatch found the reply,
selected image/title 3, and reached the expected terminal state.

## Corrective design

- Primary: Gmail Push -> Pub/Sub -> Approval Relay.
- Secondary: Google Cloud Scheduler -> independent authenticated fallback ->
  fixed GitHub workflow dispatch.
- Tertiary: existing GitHub `on.schedule`, retained as best effort.
- Six-hour read-only Gmail OAuth canary using `users.getProfile`.
- Alerts tied to Relay/OAuth/Pub/Sub/watch health and to pending business state,
  not merely cron absence.
- Seven-day Pub/Sub retention and DLQ proposed behind Human Gate.

## Safety constraints

The approval parser, token validation, Design Selection business logic,
Website/X publication logic, and 2026-09-30 output were not changed. This
document contains no sender address, mail body, complete Subject, approval
token, OAuth credential, Authorization header, or private key.
