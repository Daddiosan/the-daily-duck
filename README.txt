Fastest way to preview:
Open index.html in a browser.

Fastest way to publish:
1. Create a GitHub repository.
2. Upload all files preserving the folders.
3. Import the repository into Vercel.
4. Vercel will deploy it as a static site.

Daily workflow after launch:
1. Select one positive/notable current story.
2. Generate one original duck image.
3. Replace/update the hero copy and image.
4. Add the previous duck to Archive.
5. Human review, then publish.
